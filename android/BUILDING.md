# Build the driver app

Requires Android Studio, JDK 17, Android SDK 35 and Gradle 8.11.1.

Open this `android` folder in Android Studio. Configure the Gradle distribution as Gradle 8.11.1 and the Gradle JDK as JDK 17. Install Android SDK Platform 35 and Build Tools 35.0.0 through SDK Manager.

The Gradle 8.11.1 wrapper is bundled. From this folder run:

```sh
./gradlew :app:assembleDebug :app:lintDebug
```

On Windows use `gradlew.bat :app:assembleDebug`. The APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

Alternatively, put the complete project in your GitHub repository and run **Actions → Build and verify**. Download the `dispatch-driver-debug-apk` artifact after the build succeeds. The workflow is provided but has not been run from this deliverable.

This is a development APK, not a Play Store release. The debug signing key is generated by your build environment. Use a controlled release signing key and review current target-SDK requirements before store distribution.

For emulator testing, use `http://10.0.2.2:5080`. Physical phones require a reachable HTTPS address with a trusted certificate. Cleartext traffic is restricted to the emulator host and localhost in the debug build; the release build requires HTTPS.
